# 素材

アプリに入れる前の、元の絵。`assets/` に入っているのは、ここから切り出して
書き出したもの。作り直したくなったときに戻ってくる場所。

置いてあるだけで、アプリには含まれない（`pubspec.yaml` の `assets:` に
書いていないので、ビルドには入らない）。

## キャラクタ/

立ち絵の元。**1枚に3つ並んだ横長の絵**で、左から
**元気・ふつう・不調**の順。

`assets/organs/<臓器>/` はこれを3等分して、1枚あたり 512×1024 に。
顔は同じ絵から正方形に切り出して 256×256 にしている。

差し替えるときは、**透過が本当に入っているか**だけ先に見ること。
画面に表示された透過画像をスクリーンショットしたものは、市松模様が
絵として焼き込まれているだけで、透明度が無い。それを入れると、
ゲーム画面に灰色と白の格子の四角が出る。

## heart/ lung/ stomach/ liver/

差し替える前の立ち絵。421×843 や旧版のもの。いまは使っていない。

## 直下のもの

生成したままの絵。採用しなかったものも混ざっている。

## ここに無いもの

- **背景・敵・脳** … `assets/` に入っているものと1バイトも違わなかったので、
  二重に置いていない。`assets/bg/`・`assets/enemies/`・`assets/organs/brain/`
  がそのまま元の絵になる
- **作業中に作った確認用の画像** … 切り抜きの粗を見るために作ったもので、
  素材ではないので入れていない
